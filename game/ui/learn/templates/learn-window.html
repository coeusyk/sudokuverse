How to Play on SudokuVerse

  1. Select a cell on the board.
    The row, column and grid of the selected cell are highlighted to provide easier readability of the board.
    If the selected cell is a clue (color of number is black), then all cells having that number are highlighted as well.
  2. To add a number, click that number from the number grid.
    If the number added is incorrect, the number is shown in red, along with the reason why it was incorrect (if the number is present in the same row, column or grid).
  3. Once the board is completely filled, the game ends.
    If the number of mistakes made exceed 3, the game ends.
