About Sudoku

What is Sudoku?

Sudoku is a logic-based combinatorial number-placement puzzle. Sudoku has a 9 x 9 grid with numbers or symbols appearing in some of the squares. These numbers act as clues to fill the remaining squares. A general Sudoku has a 9 x 9 grid which is divided into 9 boxes where each box is a small 3 x 3 grid.

Its Origin

Howard Garns, an American, invented Sudoku in 1979 and originally published it in the name "Numbers in Place" in Dell Magazines. Maki Kaji, a Japanese, published a grid in 1984 in the quarterly magazine, Nikoli. He named the grid Sudoku which means single numbers in English.

How is it Played?

The player is provided with a certain number of clues should fill the remaining squares based on the following rules:

  1. Each row should have numbers 1-9, with no repeats
  2. Each column should have numbers 1-9, with no repeats
  3. Each 3x3 quadrant should have numbers 1-9, with no repeats
