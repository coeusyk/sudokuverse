Capturing how the game will interact with the user



# Identifying the User

Three options given to the user to identify themselves:-
* New Sign-up
* Login
* Guest


## New Sign-up

Ask the user to enter the following:
* Username,
* Email,
* Password,

And ask if they know how to play Sudoku:
* If yes, redirect to the **main window**.
* If no:
  * a **pop-up** should appear showing how to play Sudoku, divided into pages.
  * after they're done with the tutorial, redirect to the **main window**.


## Login

Ask the user to enter the following:
* Email
* Password

Redirect to **main window** after the user has logged in.


## Guest

Ask if they know how to play Sudoku:
* If yes, redirect to the **main window**.
* If no:
  * a **pop-up** should appear showing how to play Sudoku, divided into pages.
  * after they're done with the tutorial, redirect to the **main window**.
  


# Main Window

This is the window that will appear when a user who has been identified will start the app.

The options which will be shown to them are:
* Start a New Game
* Tutorial
* Personal Profile
* Shop
* Settings


## Start a New Game

The user will have three options of difficulty to choose from:
* Simple,
* Medium,
* Complex,

And they will have another three options of how they want to play to choose from:
* Alone
* With a friend
* With a random person


## Tutorial

This option will start a **pop-up** which will show how to play Sudoku, divided into pages.


## Personal Profile

This will redirect the user to a new window showing the following:
* Stats of the User
* Trophies/Achievements
* Social

### 1. Stats of the User

The following stats will be shown to the user:
* Previous games (W/L)
* Time taken (in each difficulty level)
  * Average time
  * Best time

### 2. Trophies/Achievements

This option will show a list of achievements that they earned by completing the requirements.

### 3. Social

This option shows the stats of the people that the user has friended.


## Settings

This enables the user to change their identification and personalise.

The options are as follows:
* Change username
* Change password
* Change display picture
* Stats visibility
  * Visible to **everyone**
  * Visible to **friends** only
  * Visible to **no one**
* Change background app theme
