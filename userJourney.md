Capturing how the game will interact with the user

# Identifying the User

Three options given to the user to identify themselves:-
* New Sign-up
* Login
* Guest

## New Sign-up

Ask the user to enter the following:
* Username,
* Email,
* Password,

And ask if they know how to play Sudoku:
* If yes, redirect to the **main window**.
* If no:
  * a **pop-up** should appear showing how to play Sudoku, divided into pages.
  * after they're done with the tutorial, redirect to the **main window**.

## Login

Ask the user to enter the following:
* Email
* Password

Redirect to **main window** after the user has logged in.

## Guest

Ask if they know how to play Sudoku:
* If yes, redirect to the **main window**.
* If no:
  * a **pop-up** should appear showing how to play Sudoku, divided into pages.
  * after they're done with the tutorial, redirect to the **main window**.
